# Changelog

## 0.3.0 — first source release candidate

- Native Hermes tools for persistent diagrams, checklists and calculators.
- QR pairing, deliberate camera handoff, shared revisioned state and return.
- Optional Mac controller: local hand preview, adaptive pointer movement,
  index-tap or pinch click, two-finger scroll, and palm-swipe app switching.
- English/Bulgarian native instructions and a gesture test page.
- Gesture Lab: an animated 21-joint hand, four guided gestures, English/Bulgarian
  instructions, playback controls and static step selection. No camera or OS
  input is used by the illustration.
- Explicit source setup, hash-locked dependencies, MIT license and security
  disclosures; clean source checks and CI for companion/native/catalog validation.

This version is a trusted-LAN prototype. See README and docs/VALIDATION.md for
tested behavior and known limitations. Catalog acceptance is a separate review.
